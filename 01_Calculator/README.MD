## 1️⃣ Calculator

A basic command-line calculator that performs common mathematical operations using Python conditions.

### Versions

#### Calculator1.py
This version uses `if`, `elif`, and `else` statements to decide which operation to run based on the user's input.

It is useful because it is easy to read, beginner-friendly, and works well when the program needs to check multiple conditions in sequence.

#### Calculator2.py
This version uses Python's `match` and `case` structure to handle the selected operation more cleanly.

It is useful because it makes multi-option logic clearer and more structured, especially when working with many fixed choices like operator symbols.

### Operations

- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Power

### Concepts Used

- Variables
- Data Types
- Operators
- Conditional Statements
- Pattern Matching
- User Input
