## 7?? Quiz Application
A dynamic, command-line quiz application built in Python that challenges users across multiple categories, evaluates responses in real-time, and calculates final metrics.

### Features

Multi-Category Interface: Select from three unique topics including Fruits & Vegetables, Animals, and Countries.
Menu Persistence Loop: Keeps the application running continuously until the user explicitly selects the exit configuration.
Robust Input Validation: Utilizes `try-except` crash-protection blocks to cleanly catch non-numeric text entry entries.
Automated Standardization: Strips whitespace and normalizes text casing so user typing errors do not trigger incorrect evaluations.
Score Summary Evaluation: Delivers dynamic string outputs summarizing accurate items out of total category variables.

### Concepts Used

- Lists
- Dictionaries
- Loops
- Conditional Statements
- Functions
- User Input
