# 11?? QR Code Generator

A Python console application that generates different types of QR codes from user-provided information.

## Features

### 1. Text QR Code

- Generates a QR code from plain text.
- Accepts text from the user.
- Saves the generated QR code as an image.

### 2. URL QR Code

- Generates a QR code from a website URL.
- Allows users to enter any valid URL.
- Saves the generated QR code as an image.

### 3. Contact QR Code

- Generates a QR code containing contact information.
- Includes name, phone number, and email.
- Uses the vCard format for easy contact sharing.

### 4. Wi-Fi QR Code

- Generates a QR code containing Wi-Fi details.
- Includes network name, password, and security type.
- Allows users to connect by scanning the QR code.

### 5. Email QR Code

- Generates a QR code containing email information.
- Supports email address, subject, and message.
- Opens the email application when scanned.

### 6. Phone QR Code

- Generates a QR code containing a phone number.
- Uses the `tel:` format.
- Allows users to quickly access the dialer.

### 7. SMS QR Code

- Generates a QR code containing SMS information.
- Includes phone number and message.
- Opens the messaging application when scanned.

### 8. Location QR Code

- Generates a QR code for a geographical location.
- Uses latitude and longitude or a map link.
- Allows users to open the location in a maps application.

### 9. Event QR Code

- Generates a QR code containing event information.
- Includes event name, date, time, and location.
- Uses the iCalendar format for event sharing.
